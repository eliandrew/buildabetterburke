# Build a Better Burke

A small static site for exploring the Burke-Gilman Trail, the connections around it, and neighborhood street improvements.

- [Home](index.html): the project landing page, with sidebar navigation and map artwork.
- [Burke-Gilman Trail](burke-gilman/index.html): 62 selectable ownership sections, source-map comparison, discussion prompts, and local notes/photos.
- [Fremont Connection](fremont-connection/index.html): eight study sections around the Ship Canal Trail, Fremont Bridge, and Burke-Gilman Trail, including nearby places and discussion tabs.
- [Stone Way N](stone-way/index.html): a completed-project case study, advocacy and project timeline, original outreach documents, and five selectable intersection designs.

Open index.html in a browser, or serve the repository directory with a static web server. No build, package installation, or backend is required. Relative links work from a local folder and when the site is hosted under a project path such as GitHub Pages.

Both map pages include navigation back home and to the other projects. Their source images and map data are embedded; the homepage shares assets from the assets directory. Its artwork comes from the existing Fremont map and retains the OpenStreetMap attribution.

Burke-Gilman observations and resized photos stay in browser local storage. Use Export data for a portable backup. Storage is tied to the browser and site address; notes from a downloaded copy do not automatically move to the hosted site. The JSON export is a backup, not an import workflow.

Ownership is transcribed from the supplied parcel PDF. Section numbers and approximate neighborhood labels are for navigation, not legal parcel boundaries. “Private Owner or Unknown” remains unresolved, and ownership does not establish maintenance responsibility. Discussion prompts are suggestions, not confirmed conditions or approved projects.

Stone Way N uses local copies of SDOT’s five design drawings. See [source notes](assets/stone-way/README.md) for provenance and the current editorial scope. The crossing explorer works with mouse and keyboard, preserves direct links to each intersection, and shows all five designs if JavaScript is disabled or the page is printed.

The Stone Way draft documents Ballard-Fremont Greenways’ advocacy from March 2023 through August 2024: construction-related access concerns, renewed outreach after the December 12 collision, SDOT’s January 26 response, business outreach, a community-group meeting, the April improvements handout, and July collaboration with Evolution Projects construction team members and an evo employee. It includes four original PDFs, a preview of the community street diagram, and organizer-supplied correspondence, with the five business replies left individually unattributed. Later entries retain the documented levy funding and October 2026 construction update. Further advocacy milestones and the exact completion date/scope remain to be supplied; completion status follows the organizer’s account.
